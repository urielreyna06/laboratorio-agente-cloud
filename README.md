# laboratorio-agente-cloud

Laboratorio 12 de Tópicos Especiales II (Prof. Regis Rivera): delegar un issue a un agente cloud
que trabaja en un entorno remoto y entrega su trabajo como rama y Pull Request para revisión humana.

Proyecto base: gestor mínimo de tareas en Python 3 (sin dependencias externas).

## Ejecutar

```
python app.py
python -m unittest discover -s tests
```
